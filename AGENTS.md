# Painel Imagine — Instruções locais

## Consulta ao vault

- No início de toda tarefa, leia `vault/Welcome.md`.
- Depois, consulte somente as notas relacionadas à tarefa. Não carregue o vault inteiro.
- Interface ou produto: use `vault/01 - Produto/` e, quando aplicável, `vault/03 - Artistas/`.
- Acesso, convites ou portal: use `vault/02 - Acesso e equipe/` e `vault/06 - Tecnologia/Rotas e fronteiras de acesso.md`.
- Importação, OneRPM ou plataformas: use `vault/04 - Dados e integrações/`, `vault/05 - Fluxos/` e `vault/06 - Tecnologia/Coletas e jobs diários.md`.
- Banco, APIs ou segurança: use `vault/06 - Tecnologia/`.

## Regras do vault

- O código e o comportamento atual do produto são a fonte de verdade caso uma nota esteja desatualizada.
- Depois de uma alteração confirmada no produto, atualize apenas as notas diretamente afetadas e, se necessário, o roadmap ou registro de decisões.
- Nunca registre no vault credenciais, tokens, variáveis de ambiente, dados pessoais ou planilhas financeiras reais.
