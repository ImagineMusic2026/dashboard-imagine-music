# Como manter este cérebro atualizado

Este cofre continua útil somente se acompanhar o painel real.

## Depois de uma alteração no produto

1. Abra a nota do módulo afetado (ex.: artistas, integrações ou permissões).
2. Atualize o que mudou: comportamento, regra de acesso, dados envolvidos e impacto para a equipe/artista.
3. Se houve escolha relevante, acrescente uma entrada em [[07 - Gestão do produto/Decisões de produto e técnica]].
4. Se surgir trabalho futuro, coloque no [[07 - Gestão do produto/Roadmap]] ou primeiro no [[98 - Inbox/INBOX]].
5. Inclua screenshot somente quando a interface estiver aprovada; não inclua dados reais ou sensíveis.

## Rotina sugerida

- **No momento da ideia:** Inbox.
- **Antes de desenvolver:** ler a nota do módulo e registrar o resultado desejado.
- **Após aprovar/publicar:** atualizar o módulo, decisão e roadmap.
- **Semanalmente:** esvaziar Inbox e revisar pendências.

## Limites

Não copie chaves, tokens, planilhas financeiras, dados pessoais ou credenciais para este cofre. Veja [[06 - Tecnologia/Segurança e dados sensíveis]].
