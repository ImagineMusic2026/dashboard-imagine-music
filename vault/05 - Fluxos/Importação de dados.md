# Importação de dados

## Roster

O painel oferece importação de roster, com análise e revisão antes da confirmação.

## OneRPM

A importação de relatórios deve validar a estrutura da planilha e trabalhar com dados agregados para evitar arquivos muito pesados e cálculos desalinhados.

## Depois da importação

Qualquer escrita ou sincronização relevante deve invalidar os caches de leitura relacionados, para que o painel não mantenha dados antigos na sessão.

Veja [[04 - Dados e integrações/OneRPM]].
